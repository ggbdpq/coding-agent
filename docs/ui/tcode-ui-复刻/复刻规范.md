# tcode 桌面 UI 复刻规范（参照 deepseek-harness + ZCode）

> 策略：先模仿再创新。布局、尺寸、交互**照搬 harness**；视觉克制原则遵循 **ZCode DESIGN.md**；品牌资产（鲸鱼 logo、Montserrat 字标、"DeepSeek" 名称、"探索未至之境"文案）**不复制**。
> 来源许可：deepseek-harness = MIT，ZCode = Apache-2.0。数值从源码 CSS 读取，移植时在 web.html 顶部注释保留署名。
> 可交互原型：`prototype.html`（零依赖，直接双击打开）。`?scene=` 可选：search / view / tooltip / project / hover / account / collapsed / settings / settings-model / chat / dark。

## 3. 尺寸

- **Sidebar**：默认 280（min 264 / max 420），折叠 rail 56，窗口 <1024 自动折叠；padding 6px 12px；底色 #F9FAFB（mac 可半透明）。顶条 52h（折叠按钮靠右）；logo 行 60h。
- **新会话按钮**：38h，r12，bg rgba(255,255,255,.55)，14/500，margin 0 2px 12px。
- **nav 行**：min-h 36，pad 7px 8px，r12，gap 8。
- **分区头**：36h，tertiary 文字；图标按钮 28px r8。展开搜索 30h r12，输入 13/18。
- **树**：项目行 34h，会话行 32h；标题 14/20，时间 10/16 tertiary；待批准：橙点 + 「待批准」。
- **菜单**：r16，pad 4，bg rgba(248,249,250,.58) + blur(40px) saturate(150%)；项 min-h 34、pad 6px 8px、r12、13/20；分组标签 11/15 tertiary；分隔线 .5px。
- **Tooltip**：bg #2C2C2E，13/20，pad 3px 7px，r8；快捷键 chip 16h。Hover 卡片：标题 #fff 14/20，路径 #CFD3D6 12/16 mono。
- **顶栏**：52–54h；会话中左标题、右等宽路径 + 面板图标。
- **Composer**：卡片 r28 + soft 阴影；输入 min-h 52（hero）；底行 pad 2px 8px 6px；`+` 28 圆；select 28h 13/20/500 secondary；发送 34 圆 #4176E6（空输入 40% 透明）。宽度 max 760。Notice 12/18 pad 4px 8px r12。
- **设置模态**：遮罩 rgba(0,0,0,.24)；面板 r28；nav 188 宽 pad 22px 12px，标题 16/24/500，项 40h r12；内容 pad 0 24px 24px；行 flex space-between pad 16 底线 .5px；主按钮近黑 #0F1115。模型卡片灰底 r20，虚线「添加模型提供商」。
- **Diff 面板**：380px，文件块 r16，头部 mono 12/18，+/- 计数绿红。

## 4. 交互与快捷键

| 动作 | 快捷键 | 说明 |
|---|---|---|
| 新会话 | ⌘N | 在当前项目下 |
| 搜索会话 | ⌘K | 展开分区头搜索；Esc 收起并清空 |
| 添加项目 | ⌘O | 系统目录选择 |
| 设置 | ⌘, | 打开模态；Esc 关闭 |
| 切换侧栏 | ⌘B | 280 ↔ 56 rail |
| 切换变更面板 | ⌘⇧D | 右侧 380 |
| 重命名会话 | ⌘⌥G | 行内编辑，Enter 确认 |

- 所有菜单：点击外部 / Esc 关闭；↑↓ 移动，Enter 选择；勾选项右侧 ✓。
- 视图选项：分组（按项目 / 按项目树 / 单列表）、排序（手动 / 最近更新）、筛选（隐藏已归档 / 全部 / 仅已归档），存 localStorage。
- 会话行 hover 出 ⋯（重命名 / 归档 / 删除）；项目行 hover 出 ⋯ + ⊕（在此项目新会话）。
- 设置即时保存，右下 toast「已保存」2s。

## 5. 不要照抄的

- 鲸鱼 logo、Montserrat 品牌字、"DeepSeek" 字样、"探索未至之境" → 用 tcode 自己的 `>_` 标记和文案。
- harness 的 React/CSS Modules 结构 → tcode 是单文件 web.html，只搬 CSS 值与 DOM 结构。
- mac 毛玻璃侧栏：Tauri/WebKit 下需 `-webkit-backdrop-filter`；不支持时退化为 #F9FAFB。
- 不用 `field-sizing: content`（WebKit 不支持），textarea 自增高用 JS。

## 6. ZCode 原则（创新阶段的约束）

冷静、密集、可操作；品牌色只用于"当前/主要动作"；技术值（路径、模型 id、耗时、版本）一律 mono；圆角嵌套由外到内递减（模态 28 → 卡片 20 → 输入 12 → chip 8）；深度克制，只给浮层阴影。
