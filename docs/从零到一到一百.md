### 2.2 从零到一的六条关键决策（新语言版必须继承）

1. **插件内核**：tool/provider/command/shell 四类 + 显式清单（不扫目录）；内核只有类型与装配。
2. **分层铁律**：kernel ← core ← providers/plugins ← shell ← main；内核不 import 任何层。
3. **权限闸门语义单份**：ask({tool,preview}) → allow/deny/always；壳只写 UI 适配。
4. **turn 是唯一事件生产者**：壳只订阅渲染（v0.3 起）。
5. **安全三道闸**：SSRF（协议白名单/字面+DNS 双查/重定向逐跳复检）、路径守卫越界标注、
   写类逐次确认——安全边界不开放替换。
6. **行为规格以 tcode 为准绳**：修 bug 五版同步；对照笔记记录语言差异。

### 2.3 0→1 阶段的真实坑（五版踩坑精华，完整版见各 docs/notes/）

- Node 类型剥离：不支持构造函数参数属性；`import type` 必须显式。
- Python 管道：`read(n)` 凑满才返回（尾巴卡死用 `read1`）；逐字节解码拆碎中文。
- Windows：taskkill /T /F 才能杀进程树；System32 的 bash.exe 是 WSL（只认 Git Bash 显式路径）；
  `GetFolderPath` 不认 HOME 重定向。
- Rust：stdlib 连 Ctrl+C 拦截都没有（两依赖政策的代价）；enum+match 是最好的判别联合。
- 通用：abort 杀父进程后孤儿孙进程握管道导致 close 迟到（改听 exit）；JSON 库默认转义中文
  （C# 需 UnsafeRelaxedJsonEscaping）；IPv6 展开形式各语言都要过标准库解析器而非字符串匹配。

### 3.3 第三批（大件，一次只做一个，触发条件见括号）

MCP 客户端（需要外接工具生态时）、Subagent（探索性任务污染主上下文成为真实痛感时）、
OS 沙箱（分发给不可信环境时）、TUI（终端体验成为主要抱怨时）。

> **2026-09-19 用户裁决：本批正式搁置，按下方触发条件回访。**
> 各条目的"实现备忘/取向"来自 docs/ZCode学习笔记.md（2026-09-27 第二轮 ZCode 研究）。
> 触发信号速查：
> - **MCP**：想让 tcode 用外部工具生态（数据库/浏览器/第三方 MCP server）时启动。
>   最小实现 = stdio 传输 + 工具发现 + 每个远端工具包一个 ToolPlugin（内核接口已兼容）。
>   实现备忘（ZCode 学习）：stdio 子进程回收要含 Windows Job Object 思路（进程树整体
>   回收）；凭证不进插件进程。
> - **Subagent**：长任务中主对话被探索性输出污染、/compact 频繁触发时启动。
>   最小实现 = core 起独立 messages 数组跑 runTurn，只回传摘要（事件模型已就绪）。
>   实现备忘（ZCode 学习）：子会话工具/权限事件换 `tool_subagent` 前缀镜像进父事件流，
>   权限请求必须镜像，否则父壳无法响应——镜像让父壳零改动看到子活动。
> - **OS 沙箱**：把 tcode 用在不可信项目 / 分发给他人 / --yolo 高频使用时启动。
>   Windows 无统一原语，成本最高，最后做。
>   实现取向（ZCode 学习）：廉价隔离优先——一次性进程 + 受限 facade 注入（参照
>   node-repl-host：Worker + 受限 process），重沙箱后置。
> - **TUI**：补全、diff 查看、面板等终端交互成为主要抱怨时启动。
>   选型：TS 生态 Ink，或接受构建步骤换 ratskin 类库（需 family 决策）。
>   前置（ZCode 学习）：先建"运行时→模型提醒"的来源描述符表（channel/lifecycle/
>   visibility，参照 system-reminder），注入类功能共用此表。
> - **检查点/rewind**（新增搁置，2026-09-27）：写类工具误改需要回退的真实需求出现时启动。
>   实现取向（ZCode 学习）：检查点 = Edit/Write 结构化输出的 first-class 事件
>   （非 git 快照、非全库复制、不依赖事件溯源全套），回退时恢复文件并注入提醒。
> - **冒烟契约上浮（conformance）**（新增搁置，2026-09-27，学自 gh/language）：
>   五版冒烟同一场景重复维护五份。触发条件：新增语言版，或同一场景在两版间出现
>   行为漂移时启动。实现取向：场景剧本收口到根级 conformance/（独立于任何实现目录，
>   见 ADR-001），五版跑绿同一套件即一致。

### 3.4 明确不做

插件市场、遥测上报、自动更新、多租户、prompt 模板引擎、事件溯源全套。

## 四、新建一门语言 xxxcode：操作手册

### 4.1 选型评估（过不了前三行就别开工）

| 评估项 | 要求 | 参考 |
| --- | --- | --- |
| stdlib TLS + JSON | 都有 → 零依赖可行；缺 JSON → +1 个 JSON 库；缺 TLS → 放弃或接受依赖 | Rust 缺两者（2 依赖）；Go/Py/C#/TS 全有（0 依赖） |
| 取消原语 | 有（ctx/signal/token）→ 轮中真取消可移植；无 → Ctrl+C 退出进程（写进局限） | Go context / C# token / TS Abort ✅；Py/Rust stdlib ❌ |
| 错误处理 | 可区分"用户中止/可重试/致命"三态 | Rust Result 枚举、Go errors.Is、C# 异常类型 |

### 4.2 步骤（每步的验收写在括号里）

1. **读参照**：通读 [tcode/src/](../impls/typescript/src/)（29 文件全读）+ 本文 §二/§三；选定语言的
   惯用表达清单（判别联合怎么写、子进程怎么杀树、SSE 怎么逐行）。
2. **脚手架**：按家族目录模板建 `kernel/ core/ providers/ plugins/{tools,commands}/
   shell/` + 入口；包管理文件只声明元数据（零依赖或登记例外）；`.gitignore`
   （构建产物 + `.<name>/` 运行目录）。（`--help` 能跑）
3. **M0 裸循环**：config（环境变量>配置文件>中文指路）→ provider（手写 SSE 流式）→
   agentloop → REPL。环境变量前缀 `<字母>CODE_*`，配置目录 `~/.<name>/`。（缺配置中文指路）
4. **M1 工具闭环**：先写四组接缝测试（edit 唯一性 / trim 裁旧留新 / netguard 判定表 /
   registry 重名拒绝）→ 实现 → 八工具逐个 TDD → 权限闸门 → 冒烟场景 A
   （正文→工具→回流→回答）。（单测全绿 + 冒烟 A）
5. **M2 会话与韧性**：JSONL 会话（schema 与家族通用）→ /resume → AGENTS.md 注入 →
   裁剪 → 重试 → 冒烟 B。（旧测试零回归 + 冒烟 B）
6. **M3 打磨**：web_fetch + netguard（判定表单测）→ 剩余命令 → 冒烟 C/D/F。
7. **R1-R3**：AgentEvent → turn 发射器 → REPL 事件渲染 → compact（+取消，若 4.1 允许）
   → 冒烟 G（三轮后 /compact 记忆保持）。（家族五版全部行为对齐）
8. **收尾**：README/ARCHITECTURE/学习指南（六层结构：一句话定义/要素类比/破误解/
   真实路径举例/行业对照/下一步）→ 真机验收（DeepSeek 紧凑流程：三轮记住暗号 →
   /compact → 复述）→ 按路径限定提交。

### 4.3 模块移植对照表（tcode → 你的语言）

| tcode 文件 | 职责 | 移植要点 |
| --- | --- | --- |
| kernel/types.ts | 线格式 + AgentEvent | 用语言惯用的判别联合（TS 联合/Py dataclass/Go struct+Type/Rs enum/C# record） |
| kernel/plugin.ts + registry.ts | 四类插件 + 注册表 | 重名拒绝必须有测试 |
| kernel/app.ts + config.ts | 装配 + 配置 | store/freshMessages 注入；不写死端点 |
| core/agentloop.ts + turn.ts | 循环 + 编排 | 40 轮熔断；错误文本回流；断尾修复；turn 唯一事件生产者 |
| core/trim.ts + compact.ts | 裁剪兜底 + 摘要 | 估算 ceil(字符/3)+8；compact 失败永不破坏会话 |
| core/session.ts | JSONL 会话 | meta+message 行；目录边界自检；/resume 换新文件 |
| core/permission.ts + systemprompt.ts | 闸门 + 提示词 | 三态语义单份；AGENTS.md 双层注入 |
| providers/* | 双协议 | SSE 手写；retry 仅首字节前；matches 首中+兜底垫后 |
| plugins/tools/* + commands/* | 八工具六命令 | 一工具一文件；skipPermission 白名单；pathguard/netguard 共用件 |
| shell/* | 壳 | 只管路由与渲染；Ctrl+C 语义按语言如实标注 |
