# ADR-001 —— 语言目录收口到 impls/

- 状态：已接受（2026-09-27）
- 决策人：用户（grilling 三轮收敛，双参照统一方案）

## 背景

仓库根层五语言目录（typescript/python/go/rust/csharp）与共享层（specs/、docs/、
references/）平铺混排，"共享契约层"的语义被淹没；五版冒烟同一场景在各实现目录里
重复维护五份——真值散落在实现目录里。

## 参照

- `E:\ggbdpq\gh\language`（一门语言 × 五实现的 monorepo）：根层放共享契约三件套
  （specs 语义规范 / conformance 独立契约套件 / schemas 机读协议），实现统一收口
  `impls/`，裁决链成文（specs > conformance > 参考实现 > 教程），"参考实现不是规范"。
- `E:\ggbdpq\gh-fork\maka`（apache/maka）：分层 workspace、runtime 语义层不持
  进程/网络权威、管/不管职责分界表。

## 决策

1. 五语言目录 `git mv` 收口至 `impls/`（保 git 历史）；
2. 根层只留共享层：`ARCHITECTURE.md`、`specs/`、`docs/`（新增 adr/）、`references/`；
3. 根相对路径引用全量更新（specs 七篇、docs 两份、README、三份跨语言 guide）；
4. 实现内部取向成文于 [ARCHITECTURE.md](../../ARCHITECTURE.md)（管/不管表 + 四条纪律）；
5. 冒烟契约上浮（五版 smoke 收敛为根级 conformance 套件）**不在本 ADR 实施**，
   登记为路线图 §3.3 搁置条目（触发条件：新增语言版或场景跨版漂移）。

## 后果

- + 根层语义清晰：契约层与实现层一眼可辨；新增语言版 = impls/ 下加目录，根层不动；
- + `.gitattributes` 统一 LF，跨平台行尾噪音（autocrlf 告警）随之消失；
- − 一次性引用更新成本（本次已付）；外部书签与旧笔记的根相对路径失效；
- − 五目录迁移后 git 状态为大规模 rename 暂存，提交前需人工扫一眼（`git status`）；
- − rust 的 `env!(CARGO_BIN_EXE_*)` 在编译期烧绝对路径：整仓搬迁后 cargo 可能认为
  测试目标仍新鲜，陈旧二进制里的旧路径导致冒烟秒挂——`touch tests/smoke.rs` 强制
  重编即愈（本次已遇，已愈）。

## 验证

迁移后四版单测 + 冒烟全绿（tcode/pcode/gcode/rcode）；ccode 因本机无 .NET SDK
未复跑（既有登记，非本 ADR 引入）。
