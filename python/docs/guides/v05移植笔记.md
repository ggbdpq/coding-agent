# v0.5 移植笔记：tcode v0.5.0 四件能力落进 pcode

结论先行：previewDiff / apply_patch / Plan Mode / Skill 索引四件全部移植，版本三处对齐 0.5.0；
单测 42→50 全绿（新增 test_diff 3、test_patch 3、test_planmode 2），冒烟 A/B/C/D/F/H 六场景全过。

| 能力 | tcode 参照 | pcode 落点 |
|---|---|---|
| previewDiff | `src/kernel/ui.ts` | `pcode/kernel/ui.py:preview_diff`（纯函数）+ `plugins/tools/edit.py:_preview` 接线（对齐 tcode edit.ts 的 preview 升级） |
| apply_patch | `src/plugins/tools/apply_patch.ts` | `pcode/plugins/tools/apply_patch.py`（needs_permission、无 skip_permission），清单挂 web_fetch 后 |
| Plan Mode | `agentloop.ts` 拒写 + `app.ts` planMode + `commands/plan.ts` | `core/agent_loop.py`（白名单与权限询问之前拦截，不发 tool_call）、`kernel/app.py:plan_mode`（YoloRef，初始 False）、`plugins/commands/plan.py`（清单挂 yolo 后） |
| Skill 索引 | `src/core/systemprompt.ts` | `pcode/core/systemprompt.py:skill_index`；build_system_prompt 在项目 AGENTS.md 段后注入 `~/.pcode/skills` 与 `<cwd>/.pcode/skills` 索引；工作原则在 edit 行后加 apply_patch 行 |

语言特有注意点：agent_loop 用 `getattr(deps.app, 'plan_mode', None)` 翻译 tcode 的 `deps.app?.planMode`（test_events 的最小替身不带该字段，不破坏既有测试）；skill_index 用 `Path.resolve` + `startswith(目录+os.sep)` 做边界自检，读失败/解码失败都只列名字（UnicodeDecodeError 也在捕获内）；apply_patch 读写均 `newline=''` 保留 CRLF（与 edit/write 同规则）；同一文件多条编辑各 next 基于同一份缓存原文、后写覆盖前写，与 tcode 行为一致未"修复"。

验证（2026-09-19，Python 3.12，Windows + Git Bash）：`python -m unittest discover -s test -v` → Ran 50 tests, OK；`python test/smoke.py` → 冒烟全部通过（A/B/C/D/F/H 六场景）；`python -m pcode --version` → pcode v0.5.0。
