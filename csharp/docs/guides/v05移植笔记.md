# v0.5 移植笔记：Plan Mode / apply_patch / Skill 索引 / diff 预览

> 移植范围：tcode v0.4 → v0.5 四件能力，文案逐字对齐；基线 v0.4.0 → 交付 v0.5.0。

| 能力 | tcode 参照 | ccode 落点 |
| --- | --- | --- |
| diff 预览 | `src/kernel/ui.ts` previewDiff | `kernel/Ui.cs` 的 `PreviewDiff`（纯函数，maxLines=40 截断标注）；`EditTool.Preview` 已接线（对齐 tcode edit.ts） |
| apply_patch | `src/plugins/tools/apply_patch.ts` | `plugins/tools/ApplyPatch.cs`：两阶段（全预验→全写入），不 override SkipPermission（白名单不豁免，与 tcode 一致）；清单挂 webfetch 之后 |
| Plan Mode | agentloop 58-65 行拒写 + plan.ts | `kernel/App.cs` 的 `PlanMode`（YoloRef）/ `core/AgentLoop.cs` 在 OnToolCall 与白名单/权限之前拒写（不发 tool_call 事件）/ `plugins/commands/Plan.cs`（清单在 approval 后、compact 前） |
| Skill 索引 | `src/core/systemprompt.ts` skillIndex | `core/SystemPrompt.cs` 的 `SkillIndex` + Build 注入 `~/.ccode/skills` 与 `<cwd>/.ccode/skills`；工作原则段在 edit 行后新增 apply_patch 行 |

C# 特有注意点：TS `slice` 自动钳位，`ctxAfter` 用 `Math.Min(len, start+2)` 防越界；`split('\n# Plan Mode（当前生效）')[0]` 两语言同语义直接对译；替换首处复用 `EditTool.ReplaceFirst`（private → internal）；同文件多编辑后写覆盖前写是有意保持的 tcode 行为，勿"修复"。

验证（先红后绿）：桩实现下 `dotnet run --project tests` → `56 通过 / 6 失败`；实现后同一命令 → `62 通过 / 0 失败`（exit=0，含 Smoke A/B/C/D/F/H）；`dotnet build` 主项目与 tests 均 0 警告 0 错误；`--version` → `ccode v0.5.0`。
