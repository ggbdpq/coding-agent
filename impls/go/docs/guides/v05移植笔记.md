# v0.5 移植笔记：tcode v0.5.0 四件能力 → gcode

先给结论：**本次把 tcode v0.5.0 的 PreviewDiff、apply_patch、Plan Mode、Skill 索引移植进 gcode，版本 0.4.0 → 0.5.0，`go vet` / `go test ./...` / `gofmt -l .` 全绿。**

- **PreviewDiff**（`internal/kernel/ui.go`）：公共前缀/后缀行收敛 + `+/-`/空格前缀 + 截断标注；edit 的 preview 由"- 旧/+ 新"截 800 升级为 PreviewDiff 接线（对齐 tcode edit.ts），并消融删除失去唯一消费方的 `truncateRunes`。
- **apply_patch**（`internal/plugins/tools/applypatch.go`，清单挂 webFetch 之后）：两阶段原子补丁，逐条错误行 `#i：…`；NeedsPermission=true 且**不设** SkipPermission（白名单不豁免，与 tcode 一致）。
- **Plan Mode 三件套**：`App.PlanMode *YoloRef`（kernel/app.go）；拒写判定在 agentloop 的白名单/权限询问**之前**——不发 tool_call 事件、直接回 tool 消息 + tool_result(ms=0)；`/plan` 命令（commands/plan.go）直接维护 Messages[0] 的 `# Plan Mode` 分节（含防重复追加与按分隔符切移除）。
- **SkillIndex**（`internal/core/systemprompt.go`）：`[~/.gcode/skills, <cwd>/.gcode/skills]` 列 `*.md` 取首行去 `#` 截 60 rune，注入在项目 AGENTS.md 段之后；工作原则在 edit 行后加 apply_patch 一行。

语言特有注意点：JS `slice` 越界自动收敛 → Go 切片需 `min` 防越界（ctxAfter）；`*Content` 指针判 nil 对齐 `content ?? ''`；中文截断一律 `[]rune`（对齐 gcode 既有 truncateRunes 惯例，tcode 是 UTF-16 码元）；apply_patch 写入失败按 gcode 工具惯例返回 `错误：写入失败：…` 文本（tcode 靠 throw 被 loop 捕获，语义等价）。

验证（2026-09-19，Windows + Git Bash）：`go vet ./...` exit=0 无输出；`go test ./...` ok 全绿（core/kernel/tools/providers/smoke，含新增 8 例：diff 3、patch 3、planmode 2，另以临时探针核过截断文案、SkillIndex 输出与 /plan 三态后删除）；`gofmt -l .` 空；`go run ./cmd/gcode --version` → `gcode v0.5.0`。
