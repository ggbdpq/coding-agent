权限

写入免审批目录

这些目录内的 write/edit 可免逐次审批；其他文件及命令仍按默认审批执行。移除目录后恢复逐次审批。

轮次结束钩子

每轮对话结束后在当前项目目录执行的 shell 命令（30 秒超时）；轮次状态经环境变量 TCODE_HOOK_STATUS 传入，stdout/stderr 会回显到会话。钩子以你的用户权限执行任意命令，请谨慎填写。

全部免审批允许工具直接执行文件修改和命令，请根据当前项目选择。
