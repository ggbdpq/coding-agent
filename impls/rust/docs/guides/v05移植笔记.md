# v0.5 移植笔记：tcode v0.5.0 第二批 → rcode

移植内容：V5-1 Plan Mode、V5-2 apply_patch 原子补丁、V5-3 preview_diff 行级 diff 预览、V5-4 Skill 索引；版本 0.4.0 → 0.5.0。
接缝位置：`kernel/ui.rs::preview_diff`（edit 的 preview 由"- 旧/＋ 新"截断升级为行级 diff 接线）；`plugins/tools/apply_patch.rs`（两阶段：全量预验→零写入或按序逐条写入；needs_permission 且不设白名单豁免）；`kernel/app.rs` 增 `plan_mode: Rc<Cell<bool>>`（对齐 yolo ref）；`core/agentloop.rs` 在白名单/闸门之前拒写（不发 tool_call 事件，只回拒写文本 + tool_result(ms=0)）；`plugins/commands/plan.rs` 直接维护 messages[0] 的 Plan Mode 分节；`core/systemprompt.rs::skill_index` 注入 `~/.rcode/skills` 与 `<cwd>/.rcode/skills` 索引 + 工作原则新增 apply_patch 一行。
语言特有注意点：JS `slice` 越界自动收敛 → Rust 切片手动 `min(len)` 夹取（ctx_after）；`replace(/^#+\s*/)` 手写为 `trim_start_matches('#')` + 条件 `trim_start`（无 # 的行保留原样，不能盲 trim）；60 字符/行数截断均按 char；edits 字段提取 `as_str().unwrap_or("")`，缺失即空串触发"#i：缺少 file_path 或 old_string"，等价 tcode 的 `?? ''`。
